Test de Diseño de Redes Seguras
Aplicación interactiva diseñada para el repaso y autoevaluación de conceptos sobre bastionado de redes y sistemas. La herramienta permite estudiar de forma estructurada los contenidos de la unidad UD0601 mediante un entorno de pruebas configurable.

Características principales
Base de datos completa: Incluye 58 preguntas clasificadas por bloques temáticos.

Organización por temas: Permite realizar simulacros de examen completos o seleccionar secciones específicas como Modelo OSI, DMZ, VLANs y Riesgos corporativos.

Sistema de evaluación oficial: Aplica una puntuación sobre 10, restando un tercio de un acierto por cada respuesta incorrecta.

Gestión de persistencia: Utiliza el almacenamiento local del navegador para guardar el progreso, permitiendo retomar exámenes inacabados.

Repaso selectivo: Opción de generar sesiones de estudio compuestas exclusivamente por las preguntas falladas en intentos anteriores.

Compatibilidad móvil: Interfaz optimizada para el uso en pantallas táctiles y dispositivos móviles.

Tecnologías utilizadas
HTML5

CSS3 con variables personalizadas

JavaScript nativo sin dependencias externas

Instrucciones de uso
Acceda al Menú Principal para seleccionar el modo de estudio.

Responda las preguntas o utilice la opción Saltar para no puntuar ni penalizar.

Consulte el desglose de estadísticas al finalizar para identificar áreas de mejora.

Si desea eliminar todo el progreso guardado, utilice la opción de borrado en el menú de configuración.
